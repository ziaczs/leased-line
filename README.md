## 专线和普通宽带差在哪

专线和家用宽带的核心区别有四点：上下行带宽对称、独享带宽、固定公网 IP、有服务质量保障。

具体说：家宽从运营商机房到你办公室要经过多级分光，整个小区或楼宇共用线路，上传速率远小于下载，每次拨号拿到的 IP 还不一样。专线是从机房直接连到你的路由设备，上行下行速率一致——100M 专线就是上下行各 100M，IP 固定不变，可以用来对外开网站、跑 FTP 服务，运营商也有专人监控线路状态。

代价是贵。写字楼里的公司基本只能装企业专线，有用户咨询过三家运营商，报价都在每月 599 元上下，而普通家宽一个月不到一百块却申请不到。另外专线分两种信道：物理专用信道是服务商到用户之间单独铺一条线，只有你在用；虚拟专用信道是在公共线路上为你保留一段独享带宽，数据加密传输，成本更低一些。

## 三种专线，办理路径完全不同

“专线”这个词覆盖了三类完全不同的业务，找错办理对象是最常见的弯路。先对照下表确认你要办的是哪一种：

| 类型 | 找谁办 | 典型用途 | 费用参考 |
| --- | --- | --- | --- |
| 企业互联网专线 | 三大运营商或本地 ISP | 办公上网、固定公网 IP、对外提供 ERP/OA 服务 | 每月数百元起 |
| 云专线 | 云厂商与线路供应商 | 本地机房连云上 VPC | 按端口规格与流量计费 |
| 跨境专线 / SD-WAN | 有国际通信资质的运营商或企业网络服务商 | 海外系统访问、跨国多点组网 | 传统国际专线 200M 独享一年 3 万元以上 |

### 企业互联网专线

找运营商，凭营业执照办理。需求很简单——办公室要固定公网 IP、要对外提供业务系统，或者写字楼压根没有普通宽带资源，那就只能走这条路。带宽按后面“带宽规划”一节的方法算，通常不需要一步到位买很大。

### 云专线（连接阿里云这类云平台）

把本地数据中心接进云上网络，需要用户、云厂商、线路供应商、机房服务商四方配合。以阿里云为例，流程大致是：

1. **选接入点**：选离本地机房最近的接入点以降低延迟。注意三大基础运营商只能走自己的专线，且不支持裸光纤接入；
2. **申请物理端口**：端口规格有 1Gbps、10Gbps、40Gbps、100Gbps 几档，只支持双纤芯接入，客户侧光模块要自己买，且规格必须与云侧一致；
3. **施工与开通**：运营商把专线铺到机房、跳线接入端口，施工全程的状态都能在控制台跟进，支付成功后端口状态才会变为 UP。

对可用性要求高的业务，可以申请多条物理专线做冗余，线路故障时流量自动切换，这个在申请端口时就要选好模式。

### 跨境专线

这是外贸和跨境电商最关心的一类，也是合规问题最集中的一类，单独说。

> 工信部的相关规定明确：未经电信主管部门批准，不得自行建立或租用专线（包括 VPN 等其他信道）开展跨境电信业务经营活动；而外贸企业、跨国企业因办公自用等原因需要跨境联网，可以向依法设置国际通信业务出入口的电信业务经营者租用相应服务。

落到操作上就两条：一是别自己买来历不明的线路、节点长期当办公网络用；二是通过有资质的渠道办理，认准能不能签正规企业合同、上游线路资源来自哪家运营商。

## 办理专线要准备哪些材料

核心材料就是一套企业资质加一份用途说明，具体包括：

- **企业注册资料**：营业执照、企业名称、注册地址、工商注册信息；
- **经营情况说明**：主要业务范围、团队规模、办公地点、运营时间；
- **申请说明**：写清办专线的用途和需求，比如是办公上网、对外提供业务系统，还是跨境访问海外平台；
- **跨境专线的额外要求**：需要说明是企业自用，线路不能被用于对外开展电信业务经营。

材料齐了之后和服务商谈合同，重点确认带宽、费用和 SLA（服务等级协议）三项，写进合同再付款。

## 办理流程五步走

从提出需求到线路开通，标准流程是：明确用途 → 算带宽 → 选服务商签合同 → 施工部署 → 测试验收。

1. **确定使用场景**：办公、跨境平台运营、多点组网还是连接云平台，场景不同方案完全不同；
2. **算清带宽需求**：方法在下一节，先算再买；
3. **选服务商、签合同**：向运营商或正规服务商要方案和报价，确认线路来源、SLA 和售后响应方式；
4. **设备与施工**：企业专线一般需要自备路由器、交换机并完成配置；云专线要按要求准备光模块；跨境组网可能涉及设备部署和线路调试；
5. **测试验收**：开通后测带宽、延迟、丢包率是否达标，跨境线路重点测目标地区的访问稳定性，确认没问题再投入使用。

## 带宽怎么算才不花冤枉钱

两个数先记住：员工办公上网按人均 1–2Mbit 估算，业务系统的专线带宽按实际并发流量算。

办公上网这块，100 个终端大概需要 100–200M，但这条需求完全可以用一条普通宽带扛。宝贵的专线资源留给服务器和业务主机：比如 2 台 OA 系统要供 10 个分支机构同时访问，按每个分支 100KB/s 算，100 × 10 × 8 = 8Mbit，一条 10M 专线就足够了。

所以性价比最高的常见做法是“小专线 + 大宽带”组合：10M 专线跑业务和对外服务，200M 普通宽带负责员工日常上网。跨境场景同理——传统国际专线 200M 独享一年报价通常在 3 万元以上，先按实际人数和场景匹配方案，比一上来追求大带宽划算得多。拿不准的话，可以把人数、目标地区和用途整理好，👉 [让 MKCloud 客服按你的场景出一份配置方案](https://bit.ly/mkcloud)。

## 常见问题

**个人能办理专线网络吗？**
传统企业专线基本面向企业，运营商受理时要营业执照。个人有跨境办公需求的，一般以团队或企业名义通过正规服务商办理，普通家用宽带无法提供固定公网 IP 和对称带宽。

**专线一个月多少钱？**
看类型。写字楼里的企业专线每月数百元起；传统国际专线 200M 独享一年通常 3 万元以上；SD-WAN 类的跨境组网方案按月付结算，百元级起步，再按人数和带宽往上加。

**办理到开通要多久？**
本地企业专线取决于线路资源，快则几天、慢则数周；云专线涉及多方施工，周期更长；跨境组网类方案部署相对快，完成配置和调试后即可测试验收。

**企业办跨境专线合法吗？**
企业因办公自用需要跨境联网，向有资质的电信业务经营者租用专线是合规路径；前提是不把线路用于对外开展电信业务经营，也不自行搭建来源不明的跨境信道。
